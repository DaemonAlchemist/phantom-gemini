# Real-World Fact Checker Skill Instructions

When triggered, your goal is to prevent logistical impossibilities by checking facts against the real world.

## Workflow

1. **Identify the Query:** Ask the user what specific logistical or physical problem needs solving (e.g., "How long does it take a body to bleed out?", "How fast can a horse travel in a day?").
2. **Research:** Use your web search tools to gather factual data.
3. **Synthesis:** Synthesize the findings into a clear, concise answer.
4. **Application:** Apply the findings directly to the scene or plot point in question, suggesting adjustments if the current draft violates physical laws or historical precedent.
5. **Format Output:** Provide a brief report. (Does not necessarily need to be saved as a file, unless it's a major piece of lore, in which case save to `01-World-Building/`).

## Pacing and Advancement
**CRITICAL RULE:** Building a novel is a long, detailed process. DO NOT RUSH THROUGH IT! Do NOT push the user to "move on." Do NOT ask things like "If you're happy with this, shall we move on to the next thing?" Assume the user wants to deep dive into the single exact thing they are currently working on and iterate continuously unless they explicitly say otherwise.
