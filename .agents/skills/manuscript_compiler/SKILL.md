# Manuscript Compiler Skill Instructions

When triggered, your goal is to assemble the final product for export or review.

## Workflow

1. **Locate Chapters:** Use your file-reading tools to list all Markdown files in the `04-Drafting/` directory.
2. **Sort and Order:** Ensure the files are ordered chronologically by chapter number.
3. **Format Assembly:** Combine the contents of all chapters into a single file. Add standard page breaks (`---`) between chapters. 
4. **Generate Title Page:** Ask the user for the Title and Author name, and prepend a basic title page to the document.
5. **Format Output:** Use your file-writing tools to save the final compiled document as `Compiled-Manuscript.md` in the root directory.
