# Onomastics Generator Skill Instructions

When triggered, your goal is to prevent random, culturally clashing names by building a basic linguistic foundation for a faction or region.

## Workflow

1. **Identify the Culture:** Ask the user what culture, faction, or region needs naming rules (e.g., "The Elven Kingdom", "The Cyberpunk Slums").
2. **Establish Phonetics:** Define the "sound" of this culture. Determine favored consonants (hard vs. soft), vowel patterns, and common suffixes/prefixes (e.g., "-ia" for cities, "-son" for lineage).
3. **Generate a Glossary:** Create a small glossary of 5-10 root words and their meanings (e.g., "dun" = hill, "garth" = fortress).
4. **Generate Names:** Produce a list of 10-15 character and location names that strictly adhere to the established rules.
5. **Format Output:** Present the linguistic rules and the generated names. Use your file-writing tools to save this linguistic guide to `01-World-Building/` under a file like `[Culture]-Linguistics.md` with YAML tags.

## Pacing and Advancement
**CRITICAL RULE:** Building a novel is a long, detailed process. DO NOT RUSH THROUGH IT! Do NOT push the user to "move on." Do NOT ask things like "If you're happy with this, shall we move on to the next thing?" Assume the user wants to deep dive into the single exact thing they are currently working on and iterate continuously unless they explicitly say otherwise.
