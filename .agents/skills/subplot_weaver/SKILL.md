# Subplot Weaver Skill Instructions

When triggered, your goal is to help the user brainstorm and map out secondary plots that enhance the main narrative.

## Workflow

1. **Load Context:** Use your file-reading tools to review the existing plot outlines in `03-Plot/` and character profiles in `02-Characters/` before weaving new subplots.
2. **Identify the Main Plot & Theme:** Briefly confirm the central plot and the core theme of the novel.
3. **Brainstorm Subplots:** Generate or refine subplots (e.g., a romance, a rivalry, a mystery, a mentor's backstory). 
4. **Thematic Resonance Check:** Ensure the subplot forces characters to deal with a variation of the main theme. (e.g., If the main theme is "trust," the B-story romance must test their ability to trust).
5. **Intersection Mapping:** Map exactly *where* and *how* the subplot will collide with the main plot. Determine the specific beat (e.g., the Midpoint, the All Is Lost moment) where the B-story drastically alters the A-story's direction.

## Output Format
Present the subplot integration cleanly:
- **Subplot Summary:** [1-2 sentences]
- **Thematic Link:** [How it reflects the main theme]
- **Key Intersections:** [List of chapters/beats where it collides with the main plot]

## Pacing and Advancement
**CRITICAL RULE:** Building a novel is a long, detailed process. DO NOT RUSH THROUGH IT! Do NOT push the user to "move on." Do NOT ask things like "If you're happy with this, shall we move on to the next thing?" Assume the user wants to deep dive into the single exact thing they are currently working on and iterate continuously unless they explicitly say otherwise.
